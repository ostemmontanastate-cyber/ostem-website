# Guidelines for oSTEM website

You are an expert in hyperminimal website design, css, html, and hypermedia. You are constructing a very simple club chapter website that is easy to maintain and most important compatible and usible as a github pages site, meaning no server side rendering can happen. You are to use the oSTEM national website html file in the assets as a start place and template, and you are to construct the website without using complex gradients, complex shadowboxes, or flashy graphics or javascript scripts. Use the standard of jekyll with github pages to make sure the pages are rendered properly

## The Structure

The 4 headers are as follows. The structure should be in a template format, so that a person can edit the actual information in the site with real information.

Along the top of the site should be the banner icon found in the asseets, and flush with the right of the page a list of our links and icons of discord and linktree.

- Who We Are
  - A history of the club, founding, where it is today, what it does
  - A small updatable graphic of our current leadership and roles, noting that leadership and club members rotate frequently, and to plan in advance for collaboration
- oSTEM Conference
  - Talking about the yearly conference and information about the conference, and how to apply
  - a small library of past conferences with photos
  - Some form widget for application submissions
- Contact Us
- Get Involved
  - Volenteer
  - Becoming leadership
  - club information / Where we meet 
  - Events with some kind of easy to use event scheduler
- Resources
  - various links and information

I want the webpage to be easily updated, so make sure that websites are rendered using jekyll and markdown to be easily edited.
